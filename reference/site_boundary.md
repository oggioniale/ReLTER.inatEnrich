# eLTER site boundary for Montagna di Torricchio

**\[experimental\]**

An `sf` object representing the boundary of the Montagna di Torricchio
eLTER site retrieved via `ReLTER::get_site_info()`.

## Usage

``` r
site_boundary
```

## Format

An `sf` object with site metadata and boundary polygon.
