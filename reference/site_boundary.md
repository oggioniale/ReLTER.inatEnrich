# eLTER site boundary for Gran Paradiso

**\[experimental\]**

An `sf` object representing the boundary of the Gran Paradiso eLTER
facility retrieved via `ReLTER::get_site_info()`.

## Usage

``` r
site_boundary
```

## Format

An `sf` object with site metadata and boundary polygon.
